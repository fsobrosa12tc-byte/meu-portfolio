## 🚀 Ecossistema de Produtos & Soluções

1. **INTEGRA CRVA (PDV, CRM & Gestão de Pátio):** Plataforma para Centros de Registro de Veículos Automotores (CRVA) com frente de caixa, recibos com validação criptográfica SHA-256, app mobile para vistorias de pátio e atendimento inteligente via WhatsApp.
2. **Finova AI:** Gestor financeiro inteligente no WhatsApp com OCR de comprovantes, importação de extratos PDF, modo anti-ilusão e análise preditiva.
3. **Nexus OS:** Plataforma corporativa de gestão de ordens de serviço, histórico de clientes e estoque técnico multi-tenant.
4. **BarberFlow AI:** Sistema vertical de agendamento automatizado com agente de IA conversacional no WhatsApp.
5. **AutoLeads AI & Sistemas Sob Medida:** CRM comercial com IA e desenvolvimento de softwares de alta complexidade sob demanda.

## 🛠️ Stack & Arquitetura (Vanilla RNF-01)

O projeto é construído sobre uma arquitetura pura e ultra-rápida, com máxima compatibilidade:
* **HTML5 Semântico:** Estrutura acessível, SEO otimizado e meta tags Open Graph.
* **CSS3 Moderno:** Design System baseado em variáveis CSS (`:root`), superfícies em **Glassmorphism** (`backdrop-filter: blur(16px)`), paleta *Deep Space Navy*, *Ciano Elétrico* e *Esmeralda Tech*, 100% responsivo (360px a 1920px).
* **JavaScript Vanilla (ES6+):**
  * **GitHub REST API (`RF-01` e `RF-02`):** Sincronização assíncrona ao vivo com os repositórios públicos de `fsobrosa12tc-byte`.
  * **EmailJS SDK (`RF-03` e `RF-04`):** Disparo de solicitações comerciais de diagnóstico em tempo real com validação e feedback visual de status.
